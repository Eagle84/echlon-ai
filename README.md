# Echlon AI — public site

Live site: **https://eagle84.github.io/echlon-ai-pages/**

This repository serves the public showcase page for **Echlon AI**, a virtual software
company staffed by AI agents: a CTO plans the work, a human approves the plan, a Dev
Lead delegates to specialist engineers, and deterministic lint/test checks decide
whether the result ships.

## About this repo

The contents of this repository are **generated**. A CI workflow in the private source
repository builds the site and pushes it here on every successful build of `main`, and
GitHub Pages serves it from the default branch.

Do not edit files here by hand — changes are overwritten on the next publish. Only the
static site is published: no application source, no configuration, and no run data.
